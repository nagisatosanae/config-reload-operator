The controller is starting in namespace {{ .Release.Namespace }}:

  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

Next, create a ConfigReloadPolicy next to a Deployment whose image has the
watcher in it. See docs/images.md in the repository for the image part.

  kubectl get configreloadpolicies -A

Before you uninstall, delete your ConfigReloadPolicy objects. The controller
takes its settings off the Deployments when a policy is deleted, and it can
only do that while it is running.
